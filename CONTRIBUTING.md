# Contributing

Thanks for your interest in Chat Computer.

- **Bugs and ideas:** open an issue in [chatcomputer](https://github.com/chatcomputer/chatcomputer/issues).
  For bugs, attach the diagnostics from **Help › Export Diagnostics**.
- **Code:** the project is preparing its 1.0 release, so features are frozen; fixes, tests and documentation
  are welcome. Please open an issue before a larger change. Read
  [AGENTS.md](https://github.com/chatcomputer/chatcomputer/blob/main/AGENTS.md) first: it lists the rules
  that are easy to break, and the test layer each kind of change needs.
- **Building:** macOS 27 on Apple silicon with Xcode 27; see the
  [README](https://github.com/chatcomputer/chatcomputer#development).
- **Security problems:** see [SECURITY.md](SECURITY.md); please don't file them as public issues.
